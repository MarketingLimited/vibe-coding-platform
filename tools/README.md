# Tools

ستُضاف في هذا المجلد سكربتات وأدوات إضافية لإدارة المنصة (مثل إنشاء المشاريع من خلال سطر الأوامر أو النسخ الاحتياطي). حالياً يعتمد التوزيع على سكربت التثبيت وأوامر Docker Compose المدمجة.

## server-setup.sh

يوفر السكربت `tools/setup/server-setup.sh` طريقة مهيّأة مسبقًا لإعداد المنصة على خادم لينكس بعد استنساخ المستودع، دون الحاجة إلى تنزيل ملفات إضافية.

```bash
sudo bash tools/setup/server-setup.sh \
  --domain example.com \
  --data-dir /srv/vibe \
  --api-port 9000
```

يقوم السكربت بالخطوات التالية:

1. التحقق من التوزيعة وتثبيت المتطلبات الأساسية (curl، git، openssl) ما لم يتم تمرير الخيار `--skip-packages`.
2. تثبيت Docker وضمان توفّر Docker Compose v2 (يمكن تخطيه باستخدام `--skip-docker`).
3. إنشاء مجلدات المنصة داخل المستودع ومجلد البيانات الدائم، بالإضافة إلى ضبط أذونات code-server.
4. توليد ملفات `.env` تلقائيًا (مع دعم `--force-env` لإعادة التوليد) بالإضافة إلى معلومات الدخول لـ code-server.
5. إنشاء شبكة Docker، وبناء الصور، وتشغيل `docker compose up -d` ما لم يتم استخدام الخيارين `--no-build-images` أو `--no-start`.
6. إنشاء سكربتات الإدارة المختصرة (`vibe-status`, `vibe-logs`, `vibe-start`, ...).

يمكن استخدام وضع التجربة عبر `--dry-run` للتأكد من دعم التوزيعة قبل تنفيذ أي تغييرات. جميع الإعدادات (`DOMAIN`, `API_PORT`, `DATA_DIR`, `API_HOST`) يمكن تمريرها أيضًا عبر متغيرات البيئة.
